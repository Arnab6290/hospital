HOSPITAL APPOINTMENTS DEMO - OFFLINE-FRIENDLY VERSION

HOW TO OPEN:
1. Extract the ZIP archive (do not open index.html from inside the ZIP).
2. Open the Hospital_Appointments_Project folder.
3. Double-click index.html. It should open in Chrome or Edge.

This version does not require React/Babel CDN scripts or a web server.
Demo data is stored locally in your browser (localStorage). No MySQL server is used.

FILES:
index.html - application page
app.js - browser interface
 db.js - demo database and sample data
style.css - project styles
 doctors.csv - doctor import sample
hospital_appointments.sql - MySQL schema and SQL version
package-lock.json - original package lock file

If the page is blank, make sure all files are in the same folder and try refreshing.
